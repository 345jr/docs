# 首页明信片化改造复盘

这个站点的「幸运四叶草」首页原本长这样：清晨草地背景上，左边是渐变标题 + 副标题文案 + 胶囊按钮 + 三张圆角特性卡片，右边是一张带漂浮动效的圆角吉祥物卡片，卡片里还叠着一个「幸运小龙 · 今日也在守护你的笔记」的胶囊 chip。

功能是完整的，素材也是精心生成的，但整体观感就是「很浓的传统 Web 味道」。本文记录这次分三步完成的改造，以及改造前的问题到底出在哪。

## 改造前：为什么看起来「很模板」

问题不是某一个元素丑，而是整套视觉语言都是从「SaaS 官网组件库」里搬来的：

### 1. 组件语言太标准，标准到没有性格

圆角卡片（`border-radius: 20px`）+ 玻璃拟态（`backdrop-filter: blur`）+ 渐变胶囊按钮 + 居中副标题——这是过去五年全世界落地页（landing page）的通用公式。每个元素单独看都「挺精致」，但组合在一起就是模板，因为你在几千个产品官网上见过一模一样的组合。

### 2. 盒套盒

吉祥物卡片（一个盒子）里面叠着一个半透明的 chip（另一个盒子），特性卡片里又套着圆角图标容器。每多一层嵌套容器，就多一层「这是 UI 组件」的心理暗示，页面离「作品」越远，离「后台系统」越近。

### 3. 为动而动

吉祥物卡片同时挂了两种动效：7 秒循环的上下漂浮，和跟随鼠标的 3D 倾斜。它们不传达任何信息，只是在说「你看我会动」。动效一旦没有叙事目的，就会从「惊喜」退化成「噪音」，还会持续消耗注意力。

### 4. 素材同质化

三张特性卡片里的图标都是同一批 AI 生成的「四叶草 + 某物体」插画，风格、构图、色调完全一致。一致性本来是美德，但三张并排摆在一起时，反而强化了「这是一套组件库的占位图」的感觉。

### 5. 氛围层浓度不够

页面本来有漂浮的四叶草和闪光星粒子，但各自只有 6 颗和 4 颗，稀稀拉拉。氛围元素有个特点：**要么密到形成气候，要么干脆没有**。几颗孤立的粒子只会让人觉得「这里好像有个没做完的装饰」。

## 改造核心思路：用实物隐喻替代 UI 组件隐喻

这次改造只做了一件事：把「卡片、chip、按钮」这些 **UI 组件隐喻**，换成「明信片、邮票、邮戳、手写落款」这些 **实物隐喻**。

实物自带人味。一张明信片不会完美对齐——它微微斜放；纸不是纯白——它是奶白或做旧的牛皮纸色；字不是 UI 字体——是手写体落款；投影不是均匀发散的——是纸压在桌面上的三层阴影。正是这些「不标准」，让页面看起来是被人摆出来的，而不是被框架渲染出来的。

## 三次迭代做了什么

### 第一步：右侧吉祥物卡片 → 明信片

- 圆角玻璃卡片改为奶白卡纸：上窄下宽的留白边（底部宽边留给落款）、整体斜放 `-2deg`、三层纸感投影
- 右上角加虚线齿孔边框的**邮票**（内嵌四叶草），左上角加双圈半透明**邮戳**
- 删掉盒内 chip，原文案改为手写体落款直接写在纸面上——和纸是一体的，不再是叠加的盒子
- 删掉漂浮与鼠标倾斜两种动效，明信片静置

暗色模式下特意**不**把明信片改成深色玻璃卡：一张真实的纸在深色桌面上依然是纸，只加深投影。实物感比「适配主题色」更重要。

### 第二步：左栏换成三张风格各异的 AI 生成明信片

左栏的副标题文案和「开始阅读」按钮全部移除，空间让给三张明信片。素材用 Seedream 生成，三种幸运元素 × 三种艺术风格，落款保留原来的特性标题，语义恰好各自呼应：

| 落款 | 素材 | 风格 | 呼应 |
| --- | --- | --- | --- |
| 写作即播种 | ![水彩四叶草](/img/home/postcard-clover-20261014-110822-0.jpg) | 水彩手绘：挂露珠的四叶草从泥土中长出 | 播种 → 破土而出 |
| 知识在生长 | ![铜刻金币](/img/home/postcard-coin-20261014-111104-0.jpg) | 复古铜版雕刻：一摞金币顶端冒出嫩芽 | 生长 → 金币上发芽 |
| 风格由你定 | ![剪纸拼贴](/img/home/postcard-collage-20261014-111132-0.jpg) | 剪纸拼贴：马蹄铁、幸运星、彩虹自由组合 | 由你定 → 自由拼贴 |

三张卡用了三种纸色（新绿、做旧牛皮纸、淡粉）和三种邮票配色，错落角度 `-4° / +1.6° / +4°`。刻意打破素材的一致性——既然主题是「收藏」，收藏就应该是各式各样、一张张攒出来的。

### 第三步：漂浮粒子加密

四叶草粒子 6 → 14 颗，闪光星 4 → 10 颗，铺满原本空旷的页面边缘。大小拉开四档（14px–40px），动画时长 8s–13.5s、延迟错开到 5.4s，避免整齐划一的复制粘贴感。粒子在 `z-index: 0` 层，从明信片背后飘过，不抢内容只造氛围。

## 沉淀下来的几条判断

:::tip[可复用的设计原则]
1. **警惕「组件库默认审美」**：圆角卡片 + 玻璃拟态 + 渐变按钮本身不坏，但它们是「零个性」的起点，不是终点。
2. **实物隐喻自带人味**：纸的斜放、手写体、做旧质感，这些「不精确」恰恰是作品感的来源。
3. **盒套盒要拆**：信息归信息，容器归容器，能合并成一层就不要套两层。
4. **动效要有叙事目的**：不传达信息的循环动效，删掉比留着好。
5. **氛围元素要么成气候要么没有**：零星的装饰粒子约等于没做。
6. **AI 生图适合造「一组各不相同」的素材**：比起让 AI 保持风格统一，给它三个完全不同的风格指令（水彩 / 铜刻 / 拼贴），产出的「收藏感」更强。
:::

## 下一步

页面目前仍保留的「模板痕迹」是顶部居中的艺术字标题区和整体的网格对称感。如果继续迭代，方向可能是：让明信片的排布更大胆（越出栅格、相互叠压）、给三张明信片加上真实的「点击进入对应文档」功能，让它们不止是装饰。
