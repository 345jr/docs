# 英灵神殿

前一段时间(2026年9月左右) ，我一直在玩&lt;英灵神殿&gt;这个游戏 ，这款游戏的早期体验版本我在大学时期就和同学玩过 ，它是一款生成冒险游戏 ，以建造基地和打怪探索大世界为主要核心玩法 ，就在那段时间附近 ，这款游戏也迎来的1.0 版本 ，有趣的是过去它其实一直是抢先体验beta版本 ，本轮大更新 ，我花了大概1个月的时间来再次体验了它

## 好与坏

随着1.0 版本的发布 ，诸多游戏媒体给了它很高的 评价 ，而我作为玩家 ，主要是分享自己的真实感受 ，首先在我心里 ，这款游戏是 8/10 ，它是一款好游戏 ，从整体设计到细节 的 各方各面 英灵神殿都做得很好 ，开放式世界的探索和流程上的循序渐进给我带来了很深的沉浸感，我们可以扮演一个维京人在一片沉迷魔幻和未知的世界上做很多探索 ，发现一些秘密 ，以及 战斗 ，没有明确的剧情，而把体验感归咎在战斗和冒险上，这或许是开放世界游戏的一种答案。(从某种角度上来说 ，它的核心玩法很像方舟生存进化很像，一句话总结就是=探索世界，提升科技，然后探索更危险的世界，获得更强大的装备 :) ) 通过诸多因素给玩家带来独特的体验感和沉浸感，它们的游戏设计团队在这方面有很高的水平，经过多年的打磨 ，现在可以算得上是一个人人皆知的知名游戏。

说完了好的办法，接下来是坏的地方，不多但是却有点致命，作为魂系游戏的爱好者，感受难度本身就是一件很有趣的事情，大家很喜欢挑战某种很难的事情，因为那样做会有成就感，但是英灵神殿的难度设计我认为存在一些问题，这或许是它没办法成为更家喻户晓的一款游戏的一个原因。最浅而易见的一个地方就是，死亡带来的进度崩坏，在默认难度下，人物死亡会掉落全部的物品，这很正常（在很多游戏里也是这样），但是拾取自己死亡掉落的物品的过程本身就是一件极其困难的事情，然后陷入到进度崩坏的循环之中，此时的玩家要么重新花费现实中的很多个小时来收集资源，做前置准备来回到自己之前的进度，要么作弊,亦或者是关掉它不玩了。背后的制作团队其实告诉玩家的一件事情就是"不要犯错"  ，对此我会扣掉1分， 保持谨慎和专注也注定让这个游戏玩起来会没那么轻松 ，提升 游戏技巧和发现游戏秘密的权重在被稀释 ，取而代之的是一些重复地无意义的 犯错惩罚和负反馈。 另外被扣掉的1分 在于 游戏交互体验 ， UI设计 面板等 ，看起来有些难操作 和原始 ，而且它没有创意工坊 ，整理箱子 和整理背包 这些常用的功能 一旦缺失 ，就会让游戏变得有点难受 （这里我感觉 ，如果官方如果默许了mod的开放程度，那么这个游戏会变得简单 ，它们希望保持难度 ，用鼠标一个个拖物品整理背包真的很难受，然后一键升级，一键放熔炼矿石这种。）游戏在N网上面其实有我提到的mod ，但是因为没有创意工坊，我就会认为官方并不重视这方面的东西，甚至是一种无声的抵制，所以我会扣1分。
