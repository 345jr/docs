# 压力退潮之后：我的偏头痛有一个 48 小时预警窗口

## 一、被误读了很多年的规律

高中第一次发作，到现在八年，总共十几次。我对它的印象一直是「毫无征兆」：某个早晨醒来，头晕，一阵阵恶心涌上来，忍不住吐了，吐完反而轻松。

但回头看，真正稳定的规律不是发作本身，而是**它和压力的关系是反的**：

> **压力最大的那段时间，它一次都不来。等我彻底松下来，某个平静的早晨，它来了。**

这件事我困惑了很久。按常识，压力大才该出事；按体感，我又确实不是「压力大」的那种人——情绪低落的日子很少，面对困难也不太有心理负担。

三条线索各自都不够解释，放在一起才对上。

## 二、它有名字：let-down headache

医学文献里叫 **let-down headache**，也叫**周末偏头痛**。描述几乎逐字对应：

> 高强度工作期完全不发作 → 压力解除后 24–72 小时内发作 → 常在第一个休息日的清晨 → 常常是「毫无征兆」地被痛醒

这不是巧合，在多项前瞻性头痛日记研究里被反复观察到，是压力与偏头痛关系里最稳定的模式之一。

**"压力期不发作"不代表压力没在起作用。** 它只是在压制和掩盖，同时在累积。

## 三、为什么高压期反而不发作

三条机制同时工作：

| 机制 | 内容 |
| --- | --- |
| **应激性痛觉减退** | 急性压力激活内源性镇痛：下丘脑—中脑导水管周围灰质（PAG）→ 下行抑制 → 脊髓背角，同时释放内源性阿片肽与去甲肾上腺素，痛阈被临时抬高 |
| **皮质醇的抗炎掩盖** | 压力期皮质醇持续偏高。而偏头痛的核心环节之一是神经源性炎症（CGRP、P 物质导致硬脑膜血管扩张、肥大细胞脱颗粒），高皮质醇在某种程度上压住了这一环 |
| **注意力被占满** | 闸门控制：压力期认知资源全被占用，对躯体信号的注意分配极低。上行传导没变，但「被感知到的部分」被大幅削减 |

一句话：**压力期是借钱，平静期是还债。**

## 四、为什么是「落地」那一刻

落地不是单一事件，是四件事同时发生：

| 压力期 | 落地后 |
| --- | --- |
| 皮质醇高 → 抗炎、抬高痛阈 | **皮质醇快速撤退** → 抗炎保护消失，炎症反弹 |
| 交感高张力 → 血管收缩、注意力占用 | **交感骤降、副交感回摆** → 血管张力剧变 |
| 内源性阿片/NA 释放 → 镇痛 | **镇痛撤退** → 痛觉回弹 |
| 节律紧绷但稳定 | **节律突然松弛**：晚睡晚起、跳餐、喝酒、忘喝水 |

注意最后一行。它最容易被忽略，也最好改：**「终于能睡个好觉」这件事本身可以是诱因。** 睡眠与偏头痛是 U 形关系，太少是诱因，**突然变多也是**。落地日常常还附带一堆次级诱因——晚起两三小时、跳过早餐、喝点酒庆祝、社交聚餐。

## 五、为什么永远在上午

我的发作全部落在上午，这也不是巧合。清晨（约 4–9 点）是偏头痛的第一高峰时段，机制叠得很彻底：

- **皮质醇觉醒反应（CAR）**：起床前后皮质醇陡升，这个"坡"本身就是触发窗口
- **夜间禁食**：8–10 小时不进食，血糖偏低；跳餐是已确认的诱因
- **夜间失水**：呼吸与皮肤蒸发丢失 300–500 ml，血容量偏低
- **REM 期**：偏头痛患者常从 REM 期被痛醒，REM 期脑血管调节波动最大
- **平卧八小时**：静脉回流与脑血流动力学改变

所以「某个早晨」的精确性可以解释成：**压力解除后第一个睡得最沉的夜晚之后的那个清晨。**

## 六、真正的发现：我在提前两天打哈欠

上面这些解释了「为什么是那个早晨」，但解释不了「为什么是那个早晨而不是别的早晨」。

答案在一个我从来没当回事的动作上：**发作前两天，我会一直打哈欠。**

这件事有三层意义。

**第一层：打哈欠是偏头痛前驱期最经典的症状之一。** 它在多项研究里排在前三位，常与疲乏、颈僵、食欲改变并列。

**第二层：它的机制直指偏头痛的启动器。** 打哈欠由下丘脑室旁核 → 海马 → 脑干这条通路驱动，核心递质是**多巴胺（尤其 D3 受体）**和催产素。而偏头痛患者有一个被反复验证的特征：**多巴胺能超敏**——用多巴胺激动剂后，打哈欠和恶心反应明显强于对照人群。这也顺手解释了为什么偏头痛常伴恶心呕吐（多巴胺 D2 作用于化学感受器触发区），以及为什么很多止吐药本质是多巴胺拮抗剂。

**打哈欠 → 恶心 → 呕吐，在递质层面是同一件事的三个表现。**

**第三层：这是近十年最重要的范式转变。** 过去认为偏头痛始于三叉神经血管系统，现在更主流的看法是——**下丘脑在发作前 24–48 小时就已经出现功能改变**，它启动了整个级联反应。而下丘脑管什么？睡眠、食欲、口渴、排尿、体温、情绪、**打哈欠**。

这份清单，恰好就是前驱期症状的全部。

所以打哈欠不是"预告"，**它是发作的早期阶段本身**。我一直把头痛那天当成起点，实际上两天前就已经开始了。

## 七、于是「毫无征兆」是一个错觉

研究显示，**30–80% 的偏头痛发作有前驱期**，在头痛前 2–48 小时开始（我的两天在正常范围内，文献里甚至报到 72 小时），而**绝大多数患者不认识它**。

为什么读不到？因为前驱期信号都是"太日常"的东西：

| 类别 | 表现 |
| --- | --- |
| 行为 | **打哈欠（最典型、最被低估）**、话变少、社交退缩、坐不住 |
| 食欲 | **特别想吃甜食/咸食**、食欲下降、恶心感 |
| 体液 | **频繁排尿**、水肿、口渴 |
| 神经 | **颈僵**、注意力下降、找词困难、畏光畏声提前出现 |
| 情绪 | 易怒、低落，或反常的兴奋与轻松 |
| 躯体 | 疲乏、肌肉酸痛、发冷 |

而我自己又叠了两层障碍：**主观压力低、内感受觉察偏弱**。倾向于把身体信号归为"没事，过会儿就好"，也需要先有一个标签，才会注意到某件事。

**没有标签，信号就滑过去了。**

## 八、这个发现为什么特别值钱

因为它绕开了一个死结。

偏头痛发作期会出现**胃轻瘫**——胃排空显著延迟，甚至伴肠麻痹。后果是：**口服药（曲普坦、NSAID）在发作期吸收很差**，吃了半天不见效，不是药不行，是没吸收。

而我会吐。所以过去的处境是：

> 等我痛到确定"这是偏头痛"，胃已经瘫了；一吐，药全白吃。

有了 48 小时预警，同一个约束就变成了机会：

> 我在**胃还正常工作**的时候，就知道 48 小时后要发作。

**这是从"治疗发作"到"拦截发作"的跃迁。** 不需要新药，不需要手术，只需要认识自己的前驱信号。

## 九、我给自己写的 if-then 规则

不搞复杂，就一条，贴在手机备忘录里：

```
IF 今天打哈欠次数明显异常（不困也打，成串）
   AND 没有明显睡眠债（睡够了照样打）
THEN 启动「预警模式」48 小时：

  【必做】
  □ 今晚固定时间睡，不熬夜；明早固定时间起（±30 min）
  □ 想补觉就早睡，不要晚起 —— 补觉不改变起床时点，晚起会
  □ 全天喝水 2 L 以上；床头放水，醒后先喝 300 ml
  □ 三餐一顿不跳，尤其早餐；随身带点吃的
  □ 零酒精
  □ 咖啡因维持原样，不加不减
  □ 不加新的高强度运动

  【安排】
  □ 不排重要会议、长途驾驶、需要精细视觉的工作

  【决策】
  □ 前几次先只做行为干预，看能不能拦下来
```

**怎么区分"我的打哈欠"和"普通打哈欠"**，这是唯一的技术难点。三个判别维度：

| 维度 | 普通打哈欠 | 前驱期打哈欠 |
| --- | --- | --- |
| 频率 | 零散，一小时 1–3 次 | **密集，成串，一小时 8–15 次** |
| 诱因 | 困、无聊、久坐、看屏幕 | **不困也打，刚睡醒也打，越打越想打** |
| 伴随 | 打完就没事 | 常伴颈僵、食欲改变、尿频、情绪变化 |
| 睡眠关系 | 补觉后消失 | **睡够了照样打** |

最有用的判别句就一句：**"我今天睡够了，但我还是在打哈欠。"**

接下来要做的只是量化：发作日和非发作日各记几天，数一数上午 10 点到 12 点之间打了多少次。有人阈值是 10 次，有人是 20 次。**这个数字一旦确定，预警系统就上线了。**

## 十、还没确定的部分

**要不要在预警期就吃药**，我没有答案，留给了医生。把两边都摆出来：

| 策略 | 证据 |
| --- | --- |
| 曲普坦在前驱期用 | **未证明优于头痛期用**。有研究显示前驱期用药不能可靠预防头痛，且约 1/4 的先兆不伴头痛，会白吃 |
| NSAID 短期预防（mini-prophylaxis） | **有支持**。这在**月经性偏头痛**里是标准做法：预计发作前 2–3 天开始萘普生 500mg bid，用 5–6 天 |

为什么我这种情况值得考虑后者：一年只 2–3 次，用药总量极低，**药物过度使用性头痛（MOH）的风险几乎为零**（门槛是每月 ≥10–15 天用药，差了两个数量级）；而且我有一个稳定、长达 48 小时、可以自我识别的预警信号——**逻辑上非常接近一个"自发版的月经性偏头痛模型"**。

所以去门诊时要说的话已经写好了：

> "我一年发作 2–3 次，每次头痛都在上午，发作前 48 小时会持续打哈欠。发作时必定呕吐，口服药吃不下。能不能考虑在预警期就开始短期 NSAID，或者给我一个非口服的备用方案？"

## 十一、两条提醒

**一、刻板性是好事，但别把一切都归进去。**

我的发作高度刻板：永远上午、永远两天哈欠前驱、永远吐。**刻板性是典型偏头痛的标志，是让人放心的。** 但反过来说，如果某次"不像平时"——下午发作、没有哈欠前驱、头痛性质变了、出现新的神经症状——那就不要按老套路处理，去看医生。典型偏头痛不该突然改变模式。

**二、"毫无征兆"到"提前两天知道"，中间隔的不是信息，是记录。**

我花了八年才发现这件事。不是因为它隐蔽，是因为我从来没往回翻过两天。

这件事的普适性大概比偏头痛本身更大：**很多"毫无规律"的东西，只是没有被记录到规律可以显形的粒度上。** 压力、睡眠、咖啡因、酒精、体重、浮力——这一串看起来彼此无关的问题，最后都收敛到同一句话：

> **把感觉换成数字。**

---

**一句话总结**

压力期是借钱，落地日是还债，清晨是扣款时间，而打哈欠是两天前发出的账单预告。

偏头痛不是"毫无征兆"的。它一直在说话，只是用的是一种我没学过的语言。
