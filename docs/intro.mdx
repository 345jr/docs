# 知识库简介

这里是 Lopop 的个人知识库，用来沉淀技术笔记、踩坑记录和各类学习文档。

## 内容组织

- 所有内容都放在 `docs/` 目录下，侧边栏会根据目录结构自动生成。
- 支持 Markdown 与 MDX（在 Markdown 中直接使用 React 组件）。
- 推送到 GitHub `main` 分支后会自动构建并部署。

## 从哪里开始

第一次维护这个知识库，建议先阅读 [如何创建新文档](/docs/create-a-document)，里面介绍了文件结构、Markdown 语法和 React 组件的用法。
